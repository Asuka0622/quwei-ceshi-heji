# 历史人物知识库 · 第一版

这是为「星笺」历史人物匹配测试建立的人物资料。候选库包含 40 位人物；另选出 20 位常见人物，以附来源的生平事实和编辑设定的趣味画像接入试用版。

## 文件

- `people.json`：40 位候选人物的结构化资料，包含身份、领域、简要事实、来源和审核状态。
- `build_seed.py`：用于生成当前初始数据的脚本。后续如果直接编辑 JSON，不应再次运行该脚本，以免覆盖人工补充。
- `reviewed-people.json`：当前试用版使用的 20 位人物，`fact` 为有链接支持的简述；`v` 为编辑设定的八维趣味画像（探索新鲜、分析问题、外向交流、计划有序、想象创造、专注深耕、进取抱负、坚守原则），而非研究测量。
- `update_website.py`：由试用版人物库生成网站使用的 `dist/people.js`，不会改动前端代码。

## 审核状态

5 位人物附有一条初步核对过的参考资料；其余 35 位暂为待查证候选，不能视为完成的传记。这里的“初步核对”只表示参考页面可支持简要事实，不等于人物画像已经验证，也不代表取得商业转载授权。

候选库的 `personality_profile` 暂为空，`matching_enabled` 均为 false。线上试用版使用的是独立的 `reviewed-people.json`。职业、作品风格、知名故事不能直接等同于人格；试用版数值仅是为了展示匹配玩法而人为设定，来源支持生平事实，不支持人物的八维评分。试用版不能视为历史学或心理学认证的匹配。

## 后续补充流程

1. 优先保留目标用户普遍熟悉的人物；知名度和传记资料丰富程度分别审核。为每位人物寻找可核对的传记或原始材料，记录具体来源、事实、争议及不确定性；避免以小说、影视演绎替代史料。知名度不能证明某人的性格资料充足。
2. 提取少量有出处的具体事例，分别记录事实和编辑者的趣味解读；不要把解读写成真实人格测量。
3. 如证据不足，不强行给各个维度打分。需要更多维度证据时保持缺失并继续研究。
4. 审核偏差和覆盖：不同时代、领域与性别；人物不应只按成就或时代身份被简单归类。
5. 对拟用于商业产品的图片、长篇文字和外部数据确认权限；数据来源链接不代表可以复制其内容。
6. 审核通过后，才能设计匹配维度、标注版本并接入网站。即使扩大人数，也不能承诺匹配具有科学准确性。

## 可使用的资料入口

- [中国历代人物传记资料库 CBDB](https://chinesecbdb.hsites.harvard.edu/)：适合查找中国历史人物的传记资料，使用时需核对具体条目与授权范围。
- [故宫博物院人物词条：苏轼](https://www.dpm.org.cn/lemmas/242068.html)
- [故宫博物院人物词条：司马迁](https://www.dpm.org.cn/lemmas/240631.html)
- [诺贝尔奖官网：爱因斯坦传记](https://www.nobelprize.org/prizes/physics/1921/einstein/biographical/)

以上来源只支持其中所列的相应事实，不自动支持人格评分，也不替代逐条审校。
